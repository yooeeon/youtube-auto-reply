# 운명원 유튜브 댓글 에이전트

최신 연애 유튜브 영상을 불러와, AI가 **영상 속 장면을 짚은 시청자 댓글**을 만들고, 내 컴퓨터의 크롬 프로필로 **한 글자씩 타이핑해 게시하고 내 댓글이 보이는지 확인**까지 하는 로컬 대시보드예요.

```
① 영상 불러오기  →  ② 영상 선택 (고민 한 줄 · 근거 장면 · 댓글 초안)  →  ③ 댓글 달기 (크롬 프로필 타이핑 · 게시 · 확인)
```

## 빠른 시작

준비물: macOS, Python 3.12+, Google Chrome, 유튜브 채널이 있는 구글 계정, (선택) YouTube Data API 키

```bash
make setup                    # .venv + 의존성 설치
```
```bash
make login PROFILE=유튜브1     # 최초 1회: 일반 크롬이 열리면 구글 로그인 → ⌘Q
```
```bash
make run                      # 대시보드 실행 → http://127.0.0.1:8000 자동으로 열림
```

`.env` (선택)
```
YOUTUBE_API_KEY=...     # 있으면 최신순 검색·뜨기 직전 찾기가 정확해요 (없으면 yt-dlp로 대체)
ANTHROPIC_API_KEY=      # 비워 두면 이 컴퓨터에 로그인된 Claude Code(구독)로 AI를 호출해요
```

## 사용법 (화면만 보고 따라 할 수 있게 만들었어요)

| 칸 | 하는 일 |
|---|---|
| ① 영상 불러오기 | [영상 불러오기] → 최신 연애 영상이 썸네일·제목·채널·올린 날짜로 떠요. 링크를 붙여 직접 추가하거나, 🔥 탭에서 뜨기 직전 영상을 찾을 수 있어요. |
| ② 영상 선택 | 영상을 누르면 AI가 자막과 인기 댓글을 읽고 **영상 속 고민 한 줄**, **근거 장면(시각+대사)**, **댓글 초안**을 보여 줘요. 초안은 직접 고칠 수 있고, 고치면 규칙 검사가 바로 다시 돌아요. |
| ③ 댓글 달기 | 프로필(자동 배정 또는 유튜브1~3)을 고르고 [댓글 달기] → 크롬 창이 화면 오른쪽에 열리고 한 글자씩 입력 → 게시 → 내 댓글 확인. 진행 상태와 결과(댓글 보기 링크·캡처)가 실시간으로 보여요. |
| 기록 | 어느 영상에 · 어느 프로필로 · 무슨 댓글을 · 성공/실패를 최신순으로 보여 줘요. 실패하면 이유와 화면 캡처가 남아요. |

버튼을 누를 수 없을 때는 항상 **이유가 문장으로** 보여요. (예: "이미 댓글을 단 영상이에요", "오늘 상한 10개를 모두 사용했어요")

## 설정 (`config.yaml`, 저장하면 서버 재시작 없이 바로 반영)

```yaml
profiles: [유튜브1, 유튜브2, 유튜브3]   # chrome-profiles/ 아래 전용 프로필 폴더
comment: { min_chars: 40, max_chars: 120, brand: 운명원 }
limits:  { daily_max_comments: 10, min_interval_sec: 60 }
```

## 운영 규칙 — 코드에서 강제

| 규칙 | 어떻게 지키나 |
|---|---|
| 영상당 댓글 1개 (계정 무관) | 게시 전 트랜잭션 검사 + DB 부분 유니크 인덱스. 화면·API를 우회해도 DB가 막아요. |
| 하루 게시 상한 (기본 10) | 한국 시간 0시 기준, 게시 중·게시 완료·확인 실패 건수로 계산 |
| 게시 간 최소 간격 (60초) | 스팸 필터에 걸리지 않도록 직전 게시 후 쿨다운 |
| 기록 | 모든 시도를 `attempts` 테이블에 시간순 기록, 실패 이유·캡처 포함 |
| 중복 게시 방지 | 게시 버튼을 누른 뒤의 실패는 재시도하지 않고 '확인 실패'로 남김 |

## 설계 이유 (제작 의도)

1. **댓글 품질을 구조로 보장한다** — 평가의 45%(맥락 25 + 유도 20)가 댓글 품질이라, LLM 한 번 호출 대신 `분석 → 후보 3개 → 규칙 검사(코드) → AI 심사` 4단계로 만들었어요. 근거 장면을 먼저 뽑고 자막에 실제로 있는 핵심어를 댓글에 꼭 넣게 해서 "그 영상에서만 나올 댓글"이 되게 했고, 규칙(길이·링크·후기 금지)은 프롬프트가 아니라 코드로 검사해요.
2. **운명원은 '해결책 정보'로 전한다** — 화자는 운명원 평판을 아는 조언자예요. `영상 속 문제 → 필요한 판단 기준 → 연애사주 → 운명원(평판)`으로 끊김 없이 이어서 광고 티를 줄였고, 이용 후기를 지어내지 않아요. (팬·헤비 유저 페르소나는 '지어낸 후기 금지' 규칙에 걸려 쓰지 않았어요.)
3. **규칙은 UI가 아니라 DB가 강제한다** — 버튼 비활성화는 안내일 뿐, 영상당 1개·하루 상한은 트랜잭션과 유니크 인덱스가 최종적으로 막아요.
4. **크롬은 전용 프로필 + 수동 최초 로그인** — 크롬은 기본 프로필 자동 제어를 막고, 구글은 자동화 브라우저 로그인을 막아요. 그래서 로그인만 사람이 일반 크롬으로 하고, 이후엔 Playwright `launch_persistent_context`가 같은 `--user-data-dir`를 재사용해요. (macOS에서 Playwright가 붙이는 `--use-mock-keychain`을 빼야 로그인 쿠키를 읽을 수 있어요.)
5. **AI는 구독 우선** — API 키가 없으면 로그인된 Claude Code CLI를 호출해 추가 비용 없이 동작하고, 키가 있으면 Anthropic API를 써요.

자세한 결정 기록은 [docs/DECISIONS.md](docs/DECISIONS.md)에 있어요.

## 개발용 명령

```bash
make check PROFILE=유튜브1                     # 자동화 크롬에서 로그인 유지 확인
make draft URL=<영상주소>                      # 초안 파이프라인만 (게시 안 함)
make dry-run URL=<영상주소> TEXT="<댓글>"      # 타이핑까지만 (게시·기록 없음)
make post-test URL=<영상주소> TEXT="<댓글>"    # 대시보드 없이 실제 게시
.venv/bin/python -m pytest -q tests           # 규칙 단위 테스트
```

## 폴더

```
app/            서버(main.py), 설정, DB·운영 규칙, AI 호출(llm.py), 유튜브·자막 수집
app/commenter/  분석 → 생성 → 규칙 검사 → 심사 파이프라인
app/poster/     크롬 프로필 열기, 게시 상태 머신, 셀렉터(한국어 UI)
web/            세 칸 대시보드 (빌드 없는 HTML/JS/CSS)
scripts/        최초 로그인 스크립트
tests/          운영 규칙·댓글 규칙 테스트
```
`chrome-profiles/`, `data/`, `.env`는 Git에 올라가지 않아요.
