# 댓글 생성 전략 (맥락 이해 25점 + 운명원 유도 20점)

> 평가의 45%가 댓글 품질이다. 그래서 "LLM 한 번 호출"이 아니라 **분석 → 생성 → 규칙 검사 → 심사**의 4단계 파이프라인으로 만들고, 각 단계 결과를 대시보드에 그대로 보여 준다.

## 1. 파이프라인

```
[입력] 자막(타임스탬프 포함) | 없으면 제목+설명  +  인기 댓글 20개  +  제목/채널
   │
   ▼ ① 분석 (Claude, 구조화 출력)
   {
     concern_one_liner: "썸 타는 남자가 답장을 늦게 하는 게 관심 없다는 신호인지 고민",
     scenes: [ {ts:"02:13", quote:"남자는 관심 있으면 바빠도 연락해요", why:"영상 핵심 주장"}, ... 2~4개 ],
     audience: { 성별/연령 추정, 시청자 감정: "공감+체념", 인기 댓글 말투 특징 },
     hooks: ["연락 텀", "읽씹"]          # 영상 고유 키워드
   }
   │
   ▼ ② 후보 생성 (Claude, N=3, 각 후보는 서로 다른 장면·페르소나·유도 방식)
   │
   ▼ ③ 규칙 검사 (결정적 Python 코드) ── 실패 후보 사유와 함께 재생성(최대 2회)
   │
   ▼ ④ AI 심사 (Claude) → 점수 + 한 줄 사유 → 최고점 선택
   │
[출력] 고민 한 줄 · 근거 장면 · 선택된 초안 · 다른 후보 2개 · 검사 배지 · 점수
```

- 모델: `claude-opus-5-5` (구조화 출력 `output_config.format` / `messages.parse`). 거절(refusal) 대비 서버측 fallback 사용.
- 분석과 생성을 나누는 이유: 요구사항이 "연애 고민을 **먼저 정리한 뒤**" 댓글을 달라고 명시했고, 근거 장면을 먼저 뽑아 두면 생성 단계가 그 장면을 **반드시 인용**하도록 강제할 수 있다.

## 2. 댓글 규칙 (코드로 검사 — `validate.py`)

| 검사 | 기준 | 비고 |
|---|---|---|
| 길이 | **공백 제외 ≥ 40자 AND 공백 포함 ≤ 120자** | 두 해석 모두 만족하는 안전 구간 (→ [D-03](DECISIONS.md)) |
| 링크 금지 | `http`, `www.`, `.com`, `.kr`, `bit.ly`, 도메인 패턴 없음 | |
| 타임스탬프 금지 | `\d{1,2}:\d{2}` 없음 | 유튜브가 자동 링크로 바꾸므로 '링크'로 볼 수 있음 |
| 해시태그 금지 | `#\S` 없음 | |
| 브랜드 | '운명원' **정확히 1회**, 첫 어절 아님 | 광고 티 방지 |
| 지어낸 후기 금지 | 운명원 주변 ±15자에 `봤는데/받아봤/보고 왔/다녀왔/상담받/후기/맞더라/소름/진짜 맞` 등 1인칭 경험 표현 없음 | 지인 경험담("친구가 봤는데 맞았대")도 금지 |
| 장면 언급 | 분석의 `scenes[*].quote` 또는 `hooks` 중 하나와 핵심어 겹침 ≥ 1 | 맥락 근거 |
| 중복 방지 | 과거 게시 댓글들과 문자 3-gram 자카드 < 0.35, 같은 문장 시작/끝 패턴 반복 금지 | "영상마다 다르게" |
| 금칙 | 이모지 과다(≤2), 욕설, 과장 광고어(최고/1위/무조건) | |

## 3. 페르소나 — "운명원 얘기를 들어 본 조언자" (D-14, D-16)

화자는 영상을 본 시청자이자, **영상 속 연애 문제를 진단하고 해결 방법을 알려 주는 조언자**다.
운명원은 **"잘 본대요", "괜찮대요", "좋대요", "잘 본다던데"** 처럼 전해 들은 주관적·긍정 표현으로만 소개한다.
"유명해요", "소문났어요", "이름난 데" 같은 단정 평판은 작위적이라 쓰지 않고(코드로 검사), 이용 경험은 절대 지어내지 않는다.

- 조언 대상: 영상 속 인물(예: "다정이한테 필요했던 건…") 또는 같은 고민을 하는 시청자("…라면").
- 말투: 인기 댓글 말투를 따라가되 단정적이고 조언하는 톤. 감탄·한탄만 하는 문장은 지양.
- **하지 않는 것**: "나도 한번 보고 싶다"류의 막연한 소망 꼬리, "단골/여러 번 봤다/소름 돋게 맞았다" 등 본인·지인 경험담 (→ 지어낸 후기 금지 규칙).

## 4. 논리 구조 — 장면에서 운명원까지 끊김 없이

광고 티는 **장면 → 운명원**이 갑자기 붙을 때 난다. 그래서 네 단계를 한 흐름으로 잇는다.

```
① 영상 속 구체적 문제  →  ② 그 문제에 필요한 판단 기준  →  ③ 그 기준을 보는 방법(연애사주)  →  ④ 그걸로 유명한 곳(운명원)
   (장면·대사 인용)          (궁합 / 결혼운 / 인연의 시기 /        (사주가 무엇을 알려 주는지)       (전해 들은 긍정)
                              재회운 / 상대 마음의 흐름)
```

| 영상 속 문제 유형 | ② 판단 기준 | 연결 문장 예 |
|---|---|---|
| 기다릴지 끝낼지 모름 | 결혼까지 갈 인연인지 | "그 사람 말 말고 다른 기준이 필요해요" |
| 사랑인지 관성인지 | 두 사람 궁합·결혼운 | "혼자 몇 년 더 끌지 말고 궁합부터" |
| 남들은 빨리 만나는데 나는 | 인연이 오는 시기 | "인연마다 시기가 다르니 그 시기를 알면" |
| 재회 고민 | 재회운·인연이 남았는지 | "붙잡을지 말지는 인연이 남았는지부터" |
| 상대 속마음을 모름 | 상대 성향·관계 흐름 | "속마음 추측만 하지 말고 관계 흐름을" |

심사(§6)의 '유도력'은 이 네 단계가 모두 있고 자연스럽게 이어지는지로 판단한다.

## 5. 예시 — '7년 연애의 끝'(보통필름) 실제 초안

| 짚은 장면 | 초안 (공백 포함/제외) |
|---|---|
| 5:28~5:33 "1년만 더 기다려 달라며" | 1년만 더 기다려 달라는 말을 3년째 듣고 있다면 그 사람 말 말고 다른 기준이 필요해요. 이 남자랑 결혼운이 닿는지 궁금하면 운명원 연애사주가 잘 맞는다더라고요 (D-16 이후 예시는 아래) |
| 4:13 "관성이지 그거" | 다정이처럼 이게 사랑인지 관성인지 헷갈리면 혼자 몇 년 더 끌지 말고 두 사람 궁합이랑 결혼운부터 확인해 보는 게 나아요. 운명원이 연애사주로 유명한 곳이라 이런 고민엔 딱일 듯 (99/73) |
| 0:18~0:37 민지는 반년 만에 결혼 | 민지는 반년 만에 결혼하고 다정이는 7년을 기다린 거 보면 인연마다 시기가 다른 거죠. 그 시기를 알면 기다릴지 끝낼지 정하기 쉬운데 운명원이 연애사주로 그걸 잘 본다고 유명해요 (99/74) |

> 참고: 과제 예시 댓글은 **공백 포함 139자 / 제외 104자**라서 공백 포함 기준이면 120자를 넘는다. 말투 참고용으로만 본다.
> D-16 이후 실제 생성 예 ('7년 연애의 끝'): "기다려 달라는 말을 36개월 들어줬으면 할 만큼 한 거예요. 이 남자랑 결혼운이 닿는지 궁금하면 운명원 연애사주가 잘 맞는다더라고요. 확인하고 정리해도 늦지 않아요"
> 위 표의 "유명한 곳 / 유명해요" 표현은 D-16으로 폐기 — 지금은 '단정 평판 없음' 검사에 걸린다.
> 폐기한 방향(v0.1): "공감 → 운명원 잘 본다던데 나도 보고 싶다" 공식 — 광고 티가 나고 장면과 운명원 사이 논리가 비어 있다는 피드백(2026-11-17)으로 폐기.

## 6. AI 심사 루브릭 (`judge.py`)

각 후보를 1~5점으로 채점, 가중합으로 선택. 점수와 사유는 대시보드에 표시.

| 항목 | 가중치 | 질문 |
|---|---|---|
| 고유성(맥락) | 0.40 | 이 댓글을 다른 연애 영상에 붙여도 말이 되는가? 되면 감점 |
| 자연스러움 | 0.30 | 실제 시청자의 조언처럼 보이는가? '나도 보고 싶다' 같은 광고 공식 꼬리가 있으면 감점 |
| 유도력 | 0.30 | 장면의 문제 → 판단 기준 → 연애사주 → 운명원(전해 들은 긍정)이 끊김 없이 이어져, 운명원이 이 고민의 해결책이라는 정보가 되는가? |

컷오프: 가중합 < 3.8 이면 재생성(최대 2회), 그래도 미달이면 최고점 + "검토 필요" 표시.

## 7. 프롬프트 설계 메모
- 시스템 프롬프트에 규칙을 **이유와 함께** 명시 (예: "타임스탬프는 유튜브가 링크로 바꾸므로 쓰지 말 것").
- 최근 게시 댓글 5개를 "이것들과 다른 문장 구조·시작어를 쓸 것" 컨텍스트로 제공.
- 재생성 시에는 직전 후보의 실패 사유와 사용한 페르소나/방식을 넣어 **다른 방향**을 강제.
- 자막은 길면 핵심 구간 위주로 압축하되 타임스탬프 유지.
