# 시연 영상 시나리오 (목표 5~6분)

> 화면 배치: **대시보드는 화면 왼쪽(약 58%)**, 게시용 크롬은 [댓글 달기]를 누르면 **오른쪽(약 42%)에 자동으로** 열려요 (`browser.layout: right`).
> 대시보드 창을 왼쪽에 맞춰 두세요 (창 크기 약 990px 이상이면 세 칸이 한 줄로 보여요).

## 촬영 전 점검표

- [ ] `make run` → 상단에 `AI: Claude 구독` · `YouTube API` · `유튜브1 ✓` 확인 (가점용이면 유튜브2·3도 ✓)
- [ ] 프로필 로그인이 의심되면 ③ 아래 [프로필 관리] → [점검]
- [ ] 시연할 영상 2~3개를 미리 골라 초안을 한 번 만들어 두기 — 초안 생성에 30~50초 걸려요. 서버를 켠 상태로 두면 다시 고를 때 바로 떠요(0.2초). (또는 촬영 후 편집으로 대기 구간 컷)
- [ ] 오늘 게시 수 여유 확인 (상단 `오늘 게시 n/10`)
- [ ] 댓글이 꺼진 영상 링크 1개 준비 (실패 처리 시연용)
- [ ] `config.yaml`의 `browser.keep_open_sec`를 8~10으로 늘려 게시 후 확인 장면이 충분히 보이게
- [ ] 화면 녹화 시 이메일 등 개인 정보 가리기

## 촬영 팁
- 타이핑 속도는 기본값(글자당 70~190ms) 유지 — 너무 빠르면 "한 글자씩" 증거가 약해요.
- 게시 후 크롬 창에서 초록 테두리가 그려진 내 댓글을 잠깐 가리키기.
- 연속 게시 사이 60초 쿨다운이 있어요. 장면 4 전에 설명을 넣거나 편집으로 컷하세요 (버튼 아래에 남은 초가 표시돼요).
